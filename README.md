Tugas Algoritma dan Pemrograman Pertemuan 7

1. Deskripsi

Tugas ini membahas fungsi, parameter, return value, dan scope dalam bahasa pemrograman Python. Program dibuat menggunakan Visual Studio Code.

2. Tujuan

- Memahami cara membuat dan memanggil fungsi.
- Memahami penggunaan parameter dan argumen.
- Memahami penggunaan return value.
- Memahami perbedaan local scope dan global scope.
- Membuat program matematika sederhana menggunakan fungsi.

3. Struktur Folder

- "latihan/": berisi lima program latihan.
- "praktik/": berisi program utama "utilitas_matematika.py".
- "README.md": berisi penjelasan tugas.
- ".gitignore": mengatur file yang tidak perlu dikirim ke GitHub.

4. Cara Menjalankan Program

1. Buka folder tugas di Visual Studio Code.
2. Buka Terminal.
3. Jalankan perintah berikut:

"python praktik/utilitas_matematika.py"

4. Pilih menu sesuai perhitungan yang ingin dilakukan.

5. Hasil Pengujian

- Luas persegi panjang dengan panjang 8 dan lebar 5 menghasilkan 40.0.
- Luas segitiga dengan alas 10 dan tinggi 6 menghasilkan 30.0.
- Jumlah bilangan dari 1 sampai 10 menghasilkan 55.
- Faktorial 5 menghasilkan 120.
- Faktorial 0 menghasilkan 1.

Melalui tugas ini, saya belajar menggunakan fungsi, parameter, return value, serta local scope dan global scope. Saya juga belajar membuat program matematika sederhana yang memiliki menu pilihan.

Saya memahami bahwa fungsi membantu membuat program lebih terstruktur dan memudahkan penggunaan kembali kode. Saya juga belajar menguji program melalui Terminal di Visual Studio Code.
